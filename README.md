# ZenPilot

面向 Chrome / Zen / Firefox 的独立侧栏网页助手，帮助你聊天、识图、点击、填表和完成网页任务。从头实现，没有复制 Curio 源码，也不是其 fork。

当前版本：**0.2.8 开发预览版**。GitHub 发布提供源码和两个浏览器安装包；尚未上架 Chrome Web Store 或 Mozilla AMO。

## 在 Chrome 安装

需要桌面 Chrome 116 或更新版本。

1. 从 Releases 下载 `zenpilot-0.2.8-chrome.zip` 并解压到固定目录。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后直接包含 `manifest.json` 的文件夹。
4. 固定 ZenPilot 扩展按钮，点击打开原生侧栏，配置 API 地址、密钥和模型。

更新时解压覆盖原目录，然后在扩展管理页点击重新加载。Chrome 版截图要求任务网页是当前可见标签页；插件不会为了截图自动切走你正在看的页面。普通聊天、用户图片、历史对话和网页操作与 Zen/Firefox 版共用实现。

从源码安装 Chrome 版：先运行 `npm ci` 和 `npm run build`，再加载 `build/chrome`。源码 `extension/manifest.json` 是 Firefox 清单，不能直接用于 Chrome。

## 第一版功能

- 空闲时自动跟随当前网页，无需手动绑定；任务开始后固定操作目标，浏览其他标签页不会改变正在执行的任务。
- 读取网页与可操作元素；点击、填写普通输入框和编辑区、选择下拉选项、滚动、按键。
- 每次操作后返回页面观察；等待元素或文字出现；连续三次操作失败时停止。
- 多标签页列表、明确切换、新建后台标签页。
- 通用网页搜索默认使用 DuckDuckGo；明确指定其他搜索引擎或站内搜索时按你的要求执行。
- 支持截图视觉分析，截图仅保留在本次模型请求上下文中。
- 逐步确认 / 自动执行；停止任务；任务步数上限；多窗口任务互不影响。
- 自定义 API 地址、密钥和模型，支持 Chat Completions 兼容接口及 OpenAI Responses。
- 冷白与蓝紫色的中文侧栏，跟随系统亮暗主题；完整对话按会话保存，支持新建、切换、搜索名称、重命名和删除。网页工具只保存简短结果，不保存网页截图。
- 用户图片附件支持选择文件、粘贴、拖入和预览；图片随对话保存。每条消息最多 4 张，原图每张最多 20 MB，发送前缩小到最长边 2048 像素并转换为 JPEG；GIF 只取首帧。
- Markdown 回复支持加粗、列表、标题、引用、表格和代码块；表格横向滚动，代码可复制。
- 默认自动判断：普通问题直接回答，只有明确需要网页时才开放网页工具。也可以选择「只聊天」，完全关闭网页工具；内部页面也能聊天。

## 在 Zen 安装测试

需要 Firefox 140 或基于 Firefox 140 或更新版本的 Zen。当前是开发预览版，尚未完成真实模型与各浏览器的完整实机兼容性验证或 Mozilla 签名。

1. 在 Zen 打开 `about:debugging#/runtime/this-firefox`。
2. 下载 `zenpilot-0.2.8-firefox.zip` 并解压，点击「临时载入附加组件」，选择解压目录中的 `manifest.json`；从源码使用则选择 `extension/manifest.json`。
3. 从扩展按钮或浏览器侧栏菜单打开 ZenPilot。
4. 点击齿轮，配置 API 基础地址（例如 `https://api.example.com/v1`，不要填完整 `/chat/completions` 路径）、密钥和模型。
5. 选择服务商支持的接口类型。模型必须支持工具调用；截图还要求视觉能力。仅兼容聊天的服务商请选择 Chat Completions；要求 Responses 的模型请选择 Responses。
6. 直接输入问题或任务。普通聊天不需要网页；需要操作网页时，插件自动识别当前页，无需手动绑定。内部调试页可以聊天，但不能被读取或操作。

临时附加组件在浏览器重启后会卸载。长期安装需要通过 Mozilla AMO 的 unlisted 渠道签名；打包 ZIP 本身不等于获得签名，不能直接作为正式安装包使用。

## 试用任务

- 「读取当前页面，找出可操作的按钮和输入框，先不要操作。」
- 「在搜索框输入机械键盘并搜索，读取前三条结果。」
- 「把姓名填成张三，邮箱填成 zhangsan@example.com，选择咨询类别，不要提交。」
- 「在新标签页打开 https://example.com ，告诉我页面标题。」

首次建议保留逐步确认，先在普通搜索页或测试表单上验证。设置中的自动执行会在下一次任务开始时生效。

## 图片与历史对话

输入框左下角「＋」添加图片，也可将截图粘贴或拖入输入框。图片可单独发送，需选择支持视觉输入的模型和 API；这项功能用于识图，不是图片生成。

右上角时钟图标打开「历史对话」。新建对话会保留原有对话；关闭或刷新侧栏后可恢复文字、用户图片与工具结果摘要。历史保存在本机浏览器扩展的 IndexedDB 中，不做跨设备同步。删除对话会同时删除其中的图片。

旧版留下的最近聊天文字会自动迁入历史；旧版已经丢弃的内容无法恢复。完整记录不会因为模型上下文上限被删除，但每次模型请求只读取最近 20 条用户/助手消息，并限制文字和历史图片总量。较早图片未进入当前请求时会向模型说明；需要重新分析时可再次附图。

## 当前限制

当前网页操作以 DOM 为主，使用合成点击与输入，某些网站会忽略这些事件。开放的 Shadow DOM 可以识别，跨域 iframe、关闭的 Shadow DOM、Canvas 控件、复杂拖拽、原生文件选择与浏览器内部页面尚不支持。截图可以看图，不提供真实坐标点击。验证码需要手动完成。

操作后观察不等于确认业务成功；模型必须根据返回页面判断。提示词要求对支付、发送、发布和删除获得明确任务授权，但自动执行模式没有可靠的语义拦截器；涉及重要提交请使用逐步确认。停止后不会发起下一步操作，已发出的网页操作无法撤回，正在页面中等待的只读工具可能短暂继续运行。

当前模型回复整段返回，工具过程实时显示；尚未实现流式文字、长任务自动压缩、任意网页 JavaScript、Anthropic 原生 Messages、文件下载管理或可复用工作流。

关闭侧栏后，任务会继续在扩展后台执行；重新打开同一对话可查看进度、确认操作或停止任务。若浏览器或扩展重启、后台进程被系统回收，正在执行的任务仍会中断，历史记录会保留，但不会自动续跑。Chrome 截图通过可见标签页接口，切换检测能丢弃已观察到的目标变化，但无法彻底消除极短时间内切换又切回的竞态。

## 数据与隐私

插件需要普通网站访问权限，以操作用户指定页面。没有内置遥测或开发者服务器。只有你配置的模型服务接收请求，包括任务、近期聊天、被读取的网页文字、元素标签，以及你要求的截图。模型服务的保存和使用规则由服务商决定；Responses 请求设置 `store: false` 不代表服务商不保留任何日志。

API 密钥存储在本机扩展存储中，没有额外加密层。远程 API 要求 HTTPS，本机 loopback 可使用 HTTP；禁止 API 重定向，避免把密钥转发到其他地址。对话文字、用户附图和工具结果摘要保存在本机，直到你删除对话或清除扩展数据；新建对话不会删除旧对话。网页工具截图仍然只在当前任务中发送，不会保存到历史。发送图片时，所选模型服务会收到图片；后续追问也可能携带最近的图片附件。

## 开发和打包

Firefox 源码可以直接加载 `extension/`；Chrome 需要生成专用清单。开发测试先运行 `npm ci`；Markdown 解析与净化库已随插件打包，不从网络加载。更新依赖后运行 `npm run vendor` 同步文件及许可证。

```text
npm test
npm run check
npm run build
npm run package
```

打包产物位于 `dist/zenpilot-0.2.8-chrome.zip` 和 `dist/zenpilot-0.2.8-firefox.zip`。测试覆盖 Chrome 后台加载、消息回调、截图目标检查、双浏览器打包，以及用户图片的两种 API 格式、完整会话持久化、普通聊天分流、Markdown 排版、标签页绑定和停止任务；不代替真实浏览器与真实模型的兼容性测试。
